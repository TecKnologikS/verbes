Licence

L'utilisation de l'application Verbes Irréguliers téléchargée sur l'App Store est régie par le contrat de licence standard de l'utilisateur final d'Apple.

Version gratuite

L'app est gratuite. La version gratuite affiche des pubs, comme le décrit la politique de confidentialité.

Achat « Supprimer les pubs »

« Supprimer les pubs » est un achat unique (non consommable), sans abonnement. Il retire les pubs de l'app ; toutes les autres fonctionnalités sont identiques dans les deux versions. Son prix est indiqué dans l'App Store avant l'achat. L'achat est associé à ton compte Apple et peut être restauré depuis l'app (Réglages → « Restaurer l’achat »). Les demandes de remboursement suivent les règles d'Apple (reportaproblem.apple.com) ; si Apple rembourse ou révoque l'achat, les pubs réapparaissent.

Contenu
